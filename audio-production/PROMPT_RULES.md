# 音乐生成提示词规则

这份文档是音乐制作平台的提示词规范。它说明模型在生成或修改音乐 JSON 时必须遵守什么，以及程序会自动检查什么。

## 1. 总原则

- 面向 6—12 岁儿童。
- 固定 C 大调、4/4 拍。
- 每段完整音乐严格为两小节、共 8 拍，可循环试听。
- 输出必须是 JSON，不输出解释、Markdown、歌词或课程文案。
- 不转调、不临时变速、不加入成人化情绪或复杂切分。
- 主题母版定义旋律身份；律动只改变速度、重音、密度和伴奏方式，不能改变主题身份。

## 2. 心情主题母版

主题母版不写具体的鼓、贝斯或萨克斯安排。它只定义核心动机、和声语言、旋律轮廓、力度和乐句呼吸，供同一种心情的四种律动共同继承。

### 四种旋律方向

| 心情 | 核心旋律方向 |
| --- | --- |
| 开心 | 向上：明亮上行与跳进，抵达高点后稳定回落。 |
| 安静 | 舒展：以级进和窄音域慢慢展开，保留呼吸。 |
| 勇敢 | 向前：清楚重复音与上行四度或五度，重心坚定。 |
| 想念 | 回望：拱形或缓慢下行，再以回望式重复留下距离感。 |

### 母版强制节拍与收束

- `coreMotif.scaleDegrees` 使用 4—8 个 1—7 的音级数字。
- `coreMotif.referenceDurations` 必须与音级一一对应。
- 所有 `referenceDurations` 相加必须严格等于 **8 拍**。
- 最后一个音必须是 `1`，也就是 `do`。
- 最后一个 `do` 至少保持 1 拍，并在第 8 拍结束，形成稳定、明亮、不突兀的收束。
- 主题和弦只使用 `C`、`Dm`、`Em`、`F`、`G`、`Am`；`primaryPlan` 固定为 4 个和弦。

示例：下面的时值总和为 8，最后以较长的 `do` 收束。

```json
{
  "scaleDegrees": [1, 3, 5, 6, 5, 3, 2, 1],
  "referenceDurations": [0.5, 0.5, 0.5, 1, 0.5, 0.5, 1, 3.5]
}
```

## 3. 完整音乐 JSON

- `bars` 固定为 `2`，总时长为 8 拍。
- `melody` 必须从第 0 拍开始。
- 最后一个旋律音必须在第 8 拍结束，不能提前结束或超过第 8 拍。
- `melody` 必须完整按顺序继承心情母版的核心动机。
- `chords` 必须继承主题母版的 4 个和弦，并从第 0、2、4、6 拍开始。
- 旋律只使用 C 大调音级，音域限制在 C4—C5；每个旋律音必须填写正确的 `solfege`（`do` 到 `si`）。

## 4. 纯编曲中的错位突出

平台是编曲工具，不依赖角色画面。因此每件乐器的“solo 感”来自错位的音区、强弱和留白，而不是所有乐器持续同时突出。

- 小熊键盘：开头清楚领奏核心动机，并承担和声。
- 小猫贝斯：在旋律停顿处安排一次有方向感的低音短句。
- 小狗鼓组：在乐句交接处安排一次易跟随的短鼓花。
- 小狮子萨克斯：在主旋律空隙写 4—6 个音组成的一小句回应。
- 避免四件乐器从头到尾叠在同一拍。

萨克斯限制：音域 C4—G5；每个音最长 0.75 拍；力度范围 55—100；每个音的开始拍必须列在 `lionAllowedBeats` 中。

## 5. 四种律动必须有不同指纹

同一心情的四个版本可以共享核心旋律和和声，但不能只改 BPM。每次生成都必须同步改变旋律时值与留白、鼓点拍位、贝斯进入位置，以及萨克斯回应的位置。

| 律动 | 必须听到的区别 |
| --- | --- |
| 稳稳走 | 均匀四分骨架、稳定根音、稀疏鼓点，不抢拍。 |
| 蹦蹦跳 | 短八分、休止、短根音和直线八分踩镲，像弹起又落下。 |
| 摇一摇 | 长短交替、弱拍轻推、根音与五度交替、稀疏非直线踩镲。 |
| 向前冲 | 连续八分推进、更多后半拍底鼓、逐步上推，不留长空白。 |

键盘弹法已经会进入模型提示词；当前 JSON 仍只记录和弦符号。要把短促和弦、左右分解和弦真正渲染成不同音符，后续还需要加入 `keyboardNotes` 数据字段。

## 6. “按意见重新生成”

用户提出修改意见时，模型会同时收到：

1. 原始提示词；
2. 当前 JSON；
3. 用户的修改意见；
4. 已同步写入提示词的 8 拍、主题继承和错位突出规则。

修改时，除非用户明确要求，否则必须保留 `kitId`、心情、律动、拍号、小节数、主题动机和基本结构。修改后的 JSON 仍须通过自动检查，之后才能重新试听。

## 7. 自动检查

平台会自动拦截以下问题：

- 母版时值不是 8 拍；
- 母版最后一个音不是 `do`，或收尾不足 1 拍；
- 完整旋律没有从第 0 拍开始、没有在第 8 拍结束；
- 核心动机或主题和弦没有继承；
- 音高、唱名、萨克斯拍点、萨克斯音域或力度不符合规则；
- JSON 格式不完整。

自动检查像一道闸门：提示词负责告诉模型应该怎么写，检查器负责阻止不合格的 JSON 进入试听和分轨。
