# 音乐生成提示词规则

这份文档是音乐制作平台的提示词规范。它说明模型在生成或修改音乐 JSON 时必须遵守什么，以及程序会自动检查什么。

## 1. 总原则

- 面向 6—12 岁儿童。
- 固定 C 大调、4/4 拍。
- 每段完整音乐严格为两小节、共 8 拍，可循环试听。
- 输出必须是 JSON，不输出解释、Markdown、歌词或课程文案。
- 不临时变速，不加入歌词或人声；其余音乐写法由当前心情和律动决定。
- 主题母版定义旋律身份；律动只改变速度、重音、密度和伴奏方式，不能改变主题身份。

## 2. 心情主题母版

主题母版不写具体的鼓、贝斯或萨克斯安排。它只定义核心动机、和声语言、旋律轮廓、力度和乐句呼吸，供同一种心情的四种律动共同继承。

### 四种旋律方向

| 心情 | 核心旋律方向 |
| --- | --- |
| 开心 | 向上：明亮上行与跳进，抵达高点后稳定回落。 |
| 放松 | 舒展：以级进和窄音域慢慢展开，保留呼吸。 |
| 勇敢 | 向前：清楚重复音与上行四度或五度，重心坚定。 |
| 想念 | 回望：拱形或缓慢下行，再以回望式重复留下距离感。 |

### 母版技术安全线

- `coreMotif.scaleDegrees` 使用 2—16 个 1—7 的音级数字。
- `coreMotif.referenceDurations` 必须与音级一一对应。
- 所有 `referenceDurations` 相加必须严格等于 **8 拍**。
- `referenceDurations` 是母版呼吸参考，不是四种律动逐音照搬的硬性时值；组合改编可以重新分配时值，但必须保留核心音高顺序并覆盖完整8拍。
- 结尾音高、音数、音符长短和收束方式不做硬性规定。
- 主题和弦只使用 `C`、`Dm`、`Em`、`F`、`G`、`Am`；`primaryPlan` 使用 1—4 个和弦。
- `primaryPlan` 只规定和弦顺序，不要求等长，也不固定每个和弦占几拍；生成母版时必须确认它能在 8 拍内找到一套与核心动机协调的自然换位方案。
- 允许切分、跨拍长音和弱拍换和弦，但换和弦瞬间正在发声的旋律音必须属于新和弦，或能在 1 拍内级进解决。
- 重拍与持续 1 拍以上的长音优先使用和弦音；短促弱拍可以使用经过音或邻音，不能在同一和弦上连续堆叠未解决的非和弦音。
- 输出前检查预想换位、重拍和长音；有冲突时先调整和弦选择或换位，再考虑局部调整音级，不能靠机械等分节奏解决。

示例：下面的时值总和为 8；这只是结构示例，不代表固定旋律或固定收束方式。

```json
{
  "scaleDegrees": [1, 3, 5, 6, 5, 3, 2, 1],
  "referenceDurations": [0.5, 0.5, 0.5, 1, 0.5, 0.5, 1, 3.5]
}
```

## 3. 完整音乐 JSON

- `bars` 固定为 `2`，总时长为 8 拍。
- `melody` 必须从第 0 拍开始。
- 最后一个旋律音必须在第 8 拍结束，不能提前结束或超过第 8 拍。
- `melody` 必须完整按顺序继承心情母版的核心动机。
- 组合生成时不可修改核心动机音高顺序、母版和弦符号及顺序或锁定鼓点；可以调整旋律时值、休止、和弦进入拍点、贝斯节奏及萨克斯的音高和进入位置。
- `chords` 必须完整继承主题母版的和弦并保持顺序；第一个和弦从第 0 拍开始，其余换和弦位置可自由安排。
- 旋律只使用 C 大调音级，音域限制在 C4—C5；每个旋律音必须填写正确的 `solfege`（`do` 到 `si`）。

## 4. 乐器协作与创作空间

平台要求四件乐器都提供可渲染的数据，但创作自由必须建立在清楚的主次和统一的时间网格上。

- 小熊键盘：承载全曲唯一的前景主旋律和主题和弦；主旋律必须给陪衬声部留下呼吸空间。
- 小猫贝斯：只允许使用 `C2、D2、E2、F2、G2、A2、B2、C3`，禁止 D3 及以上音；重拍与长音使用当前和弦根音或五度，经过音只在弱拍短暂出现并尽快解决。
- 小狗鼓组：完整保留当前律动的少儿架子鼓核心鼓型；心情只调整力度、少量装饰和第二小节细节。
- 小狮子萨克斯：只能选择完整回应乐句或柔和背景长音，不能形成第二条前景旋律。

萨克斯允许音域 A3—G5，常规推荐使用 C4—G5，需要温暖、低沉或回望感时可以使用 A3、B3。回应乐句全曲 1—2 句，每句 2—4 个连贯音、约 1.5—3 拍；背景长音全曲 1—2 个音，每音至少 1.5 拍。短于 1.5 拍的音必须与前后音连接成句，不允许每隔一两拍出现一个孤立音。`lionAllowedBeats` 只为旧数据兼容保留，可以为空。

### 声部避让

- 同一拍最多让一个有音高声部进行明显短音、切分或方向变化；其他声部使用长音、简单支撑或休止。
- 主旋律活跃时，贝斯与萨克斯至少有一个保持长音或休止。
- 主旋律与萨克斯重叠达到 0.5 拍时，禁止形成半音或全音相邻关系；优先使用三度、六度或较开阔的协和音程，无法协和时让萨克斯延后、提前结束或留白。
- 主旋律或萨克斯长音跨越换和弦时，应属于新和弦；否则必须在换和弦后 1 拍内级进解决到新和弦音。
- 第 7—8 拍进入收束区，不新增萨克斯回应、贝斯经过音或鼓组填充。

### 时间网格

- 稳稳走、蹦蹦跳、向前冲使用直拍网格，主要落在整数拍与 `n+0.5`。
- 摇一摇使用 Shuffle 三连音式网格，统一落在整数拍、约 `n+0.333` 或 `n+0.667`；不得混入 `n+0.5` 直八分弱拍。
- 和弦换拍也必须落在当前律动的时间网格上，但不要求等长或固定每几拍切换。
- JSON 拍点已经表示最终演奏位置，播放器不得对 Shuffle 版本再次施加摇摆。
- 统一网格不等于固定节奏，也不要求和弦等长；各声部仍可通过长短、留白和重音形成不同演绎。

## 5. 四种律动是同一母版的不同演绎

同一心情的四个版本必须共享核心动机与和声顺序。每种律动锁定一套来自少儿架子鼓入门练习的核心鼓型；同一种律动跨不同心情必须保留相同的底鼓、军鼓和踩镲核心拍点。模型可以根据心情调整力度、少量可选装饰和第二小节变化，不能移动或删除核心鼓点。其他乐器仍可通过节奏、重音、密度或织体自由体现差异。

| 律动 | 创作方向 |
| --- | --- |
| 稳稳走 | 四分音符基础鼓型；旋律至少70%的音从整数拍开始，贝斯使用3—5个整数拍长音，踩镲不加入弱拍。 |
| 蹦蹦跳 | 四踩加反拍踩镲；短音、休止和反弹感，像弹起又落下。 |
| 摇一摇 | 初级 Shuffle 长短鼓型；旋律至少2个三连音弱拍进入，贝斯至少6个音并包含2个三连音弱拍推动，形成持续可辨认的左右摆动。 |
| 向前冲 | 八分音符推进鼓型；更多后半拍底鼓、逐步上推，不留长空白。 |

键盘弹法已经会进入模型提示词；当前 JSON 仍只记录和弦符号。要把短促和弦、左右分解和弦真正渲染成不同音符，后续还需要加入 `keyboardNotes` 数据字段。

## 6. “按意见重新生成”

用户提出修改意见时，模型会同时收到：

1. 原始提示词；
2. 当前 JSON；
3. 用户的修改意见；
4. 已同步写入提示词的 8 拍、主题继承和错位突出规则。

修改时必须保留 `kitId`、心情、律动、速度、拍号、小节数、主题动机和母版和弦顺序；其余旋律节奏、换和弦拍点和各分轨写法都可调整。修改后的 JSON 仍须通过技术安全检查，之后才能重新试听。

## 7. 自动检查

平台会自动拦截以下问题：

- 母版时值不是 8 拍；
- 完整旋律没有从第 0 拍开始、没有在第 8 拍结束；
- 核心动机或主题和弦没有继承；
- 和弦没有从第 0 拍开始、顺序错误或换和弦拍点没有递增；
- 旋律、贝斯、鼓或萨克斯事件缺少必要字段、超出 8 拍或无法渲染；
- 音高、唱名、萨克斯音域或 MIDI 力度不符合技术范围；
- 当前律动锁定的核心鼓点缺失；
- 直拍与 Shuffle 时间网格混用，或单音乐器内部出现音符重叠；
- 主旋律与萨克斯持续相邻音摩擦超过 0.5 拍；
- 主旋律或萨克斯的持续音跨越换和弦后没有成为和弦音，也没有在 1 拍内级进解决；
- 贝斯重拍或长音没有使用当前和弦根音或五度；
- 萨克斯出现孤立短音、超过两个分离片段，或单句密集到成为第二条主旋律；
- 主旋律、贝斯和萨克斯在同一拍同时进行短音变化；
- JSON 格式不完整。
- 稳稳走缺少整数拍主导的旋律和3—5个稳定贝斯长音，或加入了弱拍踩镲；
- 摇一摇只在局部象征性使用Shuffle，旋律或贝斯缺少足够的三连音弱拍推动；

自动修复必须遵循固定优先级：先调整旋律时值、休止、和弦进入拍点、贝斯或萨克斯，再考虑非锁定装饰；不得替换母版和弦、改变核心动机音高顺序或移动锁定鼓点。审核报错会同时给出合法修复方向，避免修复一个问题时破坏另一项继承规则。

自动检查负责保证产品可运行、母版身份不丢失，并拦截明确的节奏与声部碰撞。情绪是否准确、乐句是否感人、力度层次是否自然等主观质量仍交给试听和“按意见重新生成”。
