# 动物音乐分轨台

## 最简单的启动方式

回到项目根目录，双击 `启动音乐分轨台.cmd`。浏览器会自动打开：

`http://127.0.0.1:8765`

启动后不要关闭黑色小窗口；它是本地音乐处理程序。使用结束后关闭该窗口即可停止平台。

## 使用步骤

1. 选择或拖入音乐骨架 JSON。
2. 点击“生成动物分轨”。
3. 以后可以从“已处理音乐”直接重新打开，不必重复上传和生成。
4. 点击播放，拖动每只动物的音量滑杆。
5. 可以使用“静音”或“独奏”检查单条轨道。
6. 小熊可以选择备用主旋律音色：小提琴、扬琴近似音色、尤克里里、竖琴或长笛；点击“应用音色”后重新试听。
7. 点击某条轨道的“导出单轨”，下载使用该滑杆当前音量和当前音色的独立 WAV。
8. 点击“导出当前混音”，下载所有可听轨道合成的 WAV。

备用音色只用于试听与制作选择，产品默认的小熊钢琴职责没有改变。其中 `Dulcimer` 是接近扬琴质感的通用音色，不应标注为真实中国扬琴采样。

平台不会调用百炼、MiniMax 或其他付费模型，也不会上传 API Key。JSON 和生成结果保存在本机 `audio-production/studio-data/`，该目录已从 Git 排除。

## 第一版范围

- 支持任务卡：`happy_bounce_v01`。
- 自动生成：小熊、小猫、小狗 MIDI 与 WAV。
- 小狮子使用中音萨克斯，需要先补充萨克斯短句音符。
- 小兔需要单独制作首调唱名人声。
- 未来新增组合时，需要在 `audio-production/tasks/` 放入同编号任务卡。
