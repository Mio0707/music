# Katy 唱名人声素材

本目录包含 7 个已裁切、响度对齐的人声唱名单音：

- `do.wav`
- `re.wav`
- `mi.wav`
- `fa.wav`
- `sol.wav`
- `la.wav`
- `si.wav`

- 已裁去首尾多余静音，并保留自然收尾
- 峰值约为 -3 dBFS

## 发音说明

原录音使用英语唱名 `do / re / me / fa / so / la / ti`：

- `mi.wav` 的原始发音为 `me`，听感接近“咪”。
- `sol.wav` 的原始发音为 `so`，听感接近“嗦”。
- `si.wav` 的原始发音为 `ti`，当前按项目七级唱名文件名映射为 `si`，但没有篡改或伪装原始发音。
