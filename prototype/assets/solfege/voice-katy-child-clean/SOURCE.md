# Katy 儿童声唱名（降噪版）

本目录以 `../voice-katy-child/` 为输入，在不覆盖前两个版本的前提下进行轻度清理：

- 75 Hz 以下低切，减弱低频电流声与无用振动。
- 从 9 kHz 起轻微降低高频，15.5 kHz 以上平滑截止，压低儿童化处理带来的细碎高频噪声。
- 尾部加入 30 ms 淡出，消除收尾处的轻微数字杂音。
- 重新对齐峰值，保持各唱名试听音量接近。

没有使用强力噪声门，以免破坏 `sol` 和 `si` 开头的 /s/ 辅音。
