# LAB Course Rules

这里是 LAB 音乐分析与教学内容生成规则的独立保存位置，也是后续产品建设的唯一规则来源。

## 当前版本

- 规则版本：V1.0
- 状态：已经通过 PHONK 实际产品验证和 Bossa Nova 跨风格试跑
- 适用对象：备课平台、`lab-lesson-generator` Skill、LAB 前端、内容审核
- 发布要求：AI 可以生成草案，正式课程仍需老师审核

## 各产品如何使用

### 备课平台

收集音乐风格、歌曲、年级、课堂条件等输入，按主规范生成课程草案，并让老师完成审核与发布。

### 生成 Skill

读取主规范和生活声音映射规范，以两个示例数据作为输出质量基准，生成同样结构的课程数据。

### LAB 前端

只读取审核通过的课程数据，按照统一的 7 页结构呈现，不在页面代码中重新判断教学内容。

### 内容审核

使用主规范中的音乐、教学、交互、安全、隐私和版权检查清单决定课程是否可以发布。

## 维护约定

- 主规范是规则正文，示例不能反过来覆盖规则。
- 新音乐类型先生成试跑稿和结构化数据，再进入前端实现。
- 修改通用规则时更新版本号，并至少重新检查 PHONK 与 Bossa Nova 两个案例。
- 不把商业歌曲音频、受保护采样、密钥或儿童录音放进本目录。
- 前端专用图片和声音继续放在前端资源目录，不放进规则包。
