# 动物乐队

面向 6—12 岁儿童的音乐学习与创作 Demo。孩子可以用旋律手势、身体节奏和唱名感受音乐，用动物分轨和自己的录音完成作品，也可以进入音乐实验室拆解一种音乐风格并完成集体演奏。

## 打开 Demo

浏览基础页面可以直接双击 `prototype/index.html`。

需要麦克风、乐谱识别和儿童音乐设计台时，双击 `启动唱名教学原型.cmd`，再打开：

```text
http://127.0.0.1:4174/
```

也可以在项目目录运行：

```powershell
python prototype/server.py --port 4174
```

## 当前 Demo

- 首页：感受、创作、音乐实验室，以及教师备课入口。
- 感受：画旋律、身体演奏、唱唱名。
- 身体演奏：4 种律动 × 4 种心情，共 16 课；可录制两小节节奏并带入创作。
- 创作：选择心情和律动，使用 4 个动物分轨及最多 6 张声音贴纸完成四段编排。
- 音乐实验室：当前提供完整的 PHONK LAB；孩子依次完成风格试听、三组节奏学习、分层合奏、Cowbell 与 808 听辨、三轨录音、24 小节编排和全班演出。
- 作品出口：唱古诗或做成明信片。
- 古诗：每种心情有 2—3 首候选；当前只有《静夜思》具备正式人声。
- 《静夜思》：2 小节前奏＋4 句演唱＋2 小节尾奏，四句分别使用独立练习音频。
- 合作表演：古诗演唱家、身体节奏家、旋律指挥家，以及三角色同步的集体演奏。
- 教师备课：旋律手势分析、贴纸旋律创作、乐谱唱名制作。

当前版本不在儿童端实时生成旋律、古诗人声或 LAB 课程。儿童音乐设计台的线上演示读取已经生成好的固定音乐包；正式模型调用只在本地服务或未来的备课后台完成。

## 主要文件

- `prototype/app.js`：页面逻辑与交互。
- `prototype/styles.css`：界面样式。
- `prototype/assets/music/`：音乐包、古诗人声和乐谱数据。
- `prototype/assets/stickers/`：动物与动作素材。
- `prototype/tests/`：当前 Demo 的自动校验。
- `lab-course-rules/`：LAB 音乐分析与教学内容生成规则、参考规范和验证案例。
