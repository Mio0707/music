# 儿童音乐学习产品

这个项目帮助6—12岁儿童先听懂音乐，再用拍手、动物乐队和AI支持完成自己的作品。

## 核心文档

- [PRODUCT.md](PRODUCT.md)：唯一的产品方案，包含教学、创作、动物乐队、AI边界和Demo规则。
- [AUDIO_PRODUCTION.md](AUDIO_PRODUCTION.md)：80条贴纸音频的音乐语言、MiniMax主流程、Mureka备选流程、提示词、检查与换电脑规则。
- `README.md`：项目入口、当前状态和使用方法。

历史讨论、零散理论和旧任务表已经关闭，不再作为产品依据。

## 当前成果

- `prototype/index.html`：可点击核心流程原型。
- `prototype/app.js`、`prototype/styles.css`：原型交互与视觉。
- `prototype/assets/stickers/`：五只动物的头像和演奏贴纸。
- `prototype/assets/stickers/body-rhythm/`：小狗桌面节奏课程动作图。
- `materials/义务教育艺术课程标准（2022年版）.pdf`：课程标准原件。
- `output/`：竞品实测截图。

## 打开原型

直接双击 `prototype/index.html`。

如需测试麦克风或乐谱识别流程，双击 `启动唱名教学原型.cmd`，然后打开 `http://127.0.0.1:8767/`。

也可以在项目目录运行：

```powershell
python prototype/server.py --port 8767
```

然后打开 `http://127.0.0.1:8767/`。

## 当前版本

已完成：

- 教师备课平台已整合为三个入口：歌曲分析支持旋律手势与身体演奏，乐谱生成唱名支持唱唱名课堂，贴纸旋律创作支持“创作”。
- 歌曲分析当前只上传音频，在浏览器本地分析有效声音区间、拍点、速度、拍号候选和旋律轮廓，不调用AI。
- 已加入按真实音乐时间定位手势、播放进度高亮、休止水平线和自适应手势切换速度。
- 手势库已分为通用、3/4专用和4/4专用，并增加三叶花、三拱线等差异化图形；封闭图形保留开口或起点。
- “画旋律”由穿黑色短袖的小猫带领；“唱唱名”仍由小兔承担。
- 教师模式、内置示范歌曲、旋律线和身体演奏。
- 投屏课堂到儿童创作的衔接。
- 情绪选择和精简后的贴纸创作入口。
- 小狗、小熊、小猫和小狮子的四段编排和纸偶舞台；小兔保留在“唱唱名”学习中，不作为循环旋律贴纸进入创作。
- 唱名课堂已改为每页4个小节、点击“演唱”播放；默认使用钢琴，也可使用按唱名和八度保存在本机的自定义录音，缺失录音时自动回退到钢琴。歌词演唱留到后续版本。
- 原始实时混音与轻量AI优化对比；AI不重新作曲。
- 儿童作品转旋律线与身体演奏、音乐明信片和“一起演”。
- 小狮子已由吉他改为萨克斯。
- 16 组“感觉 × 律动”正式音乐素材已经接入 Demo；五只动物的正式分轨均已验证，创作使用其中小狗、小熊、小猫和小狮子四条分轨。
- “感受 → 身体演奏”已经接入4个基础律动 × 4种心情的16课桌面节奏课程，固定使用“敲桌面、敲近身桌沿、拍手”三种动作。
- 每课支持只听小狗、慢速练习、跟音乐练习、四拍准备、静音录制两个小节、试听和本机保存。
- 创作页可以为小狗选择“系统节奏”或当前心情与律动对应的“我的录制”；自录节奏已接入完整乐队试听、单段试听和完整作品混音。
- 原有“我的声音贴纸”仍可独立录制生活声音、唱歌、哼唱、说话或拟声，并与动物分轨叠加。
- 教师端已加入《东方红》乐谱校对流程：共16个小节，每页显示4个小节；弱起音保留在原谱第一小节。音高、八度、长度、歌词和音符数量均可修改，实时简谱同步更新。发布后学生点击“演唱”即可听当前页，可选择钢琴或本地录制的唱名；当前Demo的通用乐谱识别准确率仍需继续完善。
- 固定演示包位于 `prototype/assets/demo/`：`fixed-demo.json` 负责登记两首演示课，`dongfanghong.json` 保存东方红最终乐谱；卡门音频与手势方案、七个基础唱名音频和钢琴播放规则均从前端本地资源读取。

下一步重点：

1. 用儿童实际测试16课的动作辨识、跟随难度、桌沿安全性和录音质量。
2. 在桌面版本确认后，设计无桌面版本和双人合作版本。
3. 完整体验“教师教学—儿童创作—作品再教学—作品配音—音乐明信片”闭环。
4. 使用更多不同拍号和带空拍的音频校验自动小节划分、拍号判断与手势匹配。
5. 让儿童作品的旋律线和身体动作根据实际编排变化，并验证后续古诗歌曲生成。

当前修改只在本地；完成检查后再统一提交并上传。
