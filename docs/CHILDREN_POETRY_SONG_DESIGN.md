# 儿童古诗歌曲设计与生产规则

> 更新时间：2026-08-10  
> 适用范围：面向 6—12 岁儿童的预制古诗歌曲包，以及二期“心情 × 律动”批量生产工作流。

## 1. 核心结论

儿童古诗歌曲不应先锁定某一种音阶，而应按以下优先级设计：

> 儿童可唱性（硬约束）→ 古诗句法与韵脚（结构约束）→ 汉语声调（软约束）→ 调式与音色（风格选择）

五声音阶可以帮助形成中国清雅感，但不是古诗歌曲的必选条件。真正影响儿童跟唱的是有限音域、清楚句法、自然节奏、重复轮廓、歌词清晰度和换气位置。

## 2. 歌曲设计规则

### 2.1 音域与音程

- 默认旋律音域控制在六度至八度，并允许整体移调。
- 6—8 岁优先从六度左右开始；9—12 岁可逐步扩展到一个八度。
- 相邻音以同音、二度和三度为主；四度用于强调。
- 五度以上跳进谨慎使用，跳进后尽量级进返回。
- 一句主要使用 3—6 个音高，避免连续大跳和频繁换区。
- 先让孩子能模仿旋律大致走向，再增加装饰音。

### 2.2 调式与和声

可提供三种音乐语言：

| 类型 | 音乐材料 | 适用体验 |
| --- | --- | --- |
| 现代儿歌型 | 大调或小调、清楚和弦 | 亲切、易理解、易跟唱 |
| 中国清雅型 | 五声材料、更多留白 | 安静、诗意、传统文化氛围 |
| 吟诵型 | 接近语言起伏 | 突出句法、停顿和平仄感 |

规则：

- 古诗不强制使用五声音阶。
- 只使用 `1、2、3、5、6` 不等于自然形成中国风；还要检查中心音、句尾落音、留白、装饰和音色。
- 伴奏可以使用现代和声，但不能遮盖歌词或与人声调性冲突。
- 最后一句通常回到稳定中心音，形成明确结束感。

### 2.3 句法、节奏与换气

- 五言句优先按“2＋3”组织。
- 七言句优先按“2＋2＋3”组织。
- 默认一字一音；一字多音只用于韵脚、长音或情感重点。
- 不能把每个字机械地分配成完全相同的时值。
- 每句要有清楚起点、句尾延长和换气空间。
- 韵脚适度延长；四声字不应无目的地拖长。
- 多音字必须在生产前确认正确读音。
- 速度不能只看 BPM，还要看每个字占用的拍数。唱起来断裂时，应先缩短单字时值、调整弱起和分组，而不是直接加快整首歌。

### 2.4 汉语声调

汉语声调只作为软约束，不机械规定“一声唱高、三声先低后高”。发布前检查：

- 双字词的相对高低是否严重反向；
- 关键词是否落在稳定音或较长时值；
- 句意重心和旋律重音是否一致；
- 四声字是否被过度拉长；
- 歌词在完整伴奏中是否仍然清楚。

音高正确但听不清歌词，仍判定为不合格。

### 2.5 乐句结构与记忆

- 短诗优先使用 `A—A'—B—A''`。
- 第一句建立主题，第二句相似重复，第三句向上发展或形成对比，第四句回落并收束。
- 同一核心动机至少重复一次，再做小变化。
- 减少无目的装饰、连续切分和过多旋律材料。
- 前奏提供速度和进入提示，尾奏帮助共同收束。

## 3. 标准歌曲结构

当前一期优先采用 4/4 拍、8 小节结构：

| 小节 | 功能 | 人声 |
| --- | --- | --- |
| 1—2 | 前奏，建立速度与心情 | 无 |
| 3—6 | 四句古诗，每句一小节 | 有 |
| 7—8 | 尾奏，共同结束 | 无 |

每句必须同时输出：

- 在完整时间轴中的起拍和时值；
- 整首人声中的对应位置；
- 一条独立逐句练习音频；
- 句尾停顿或换气标记。

以后可以扩展其他结构，但同一歌曲包的伴奏、人声、歌词、简谱和手势必须共用一条时间轴。

## 4. 心情与律动适配

### 4.1 心情标签

- 开心：明亮、轻快、上行倾向。
- 放松：平稳、留白、柔和收束。
- 勇敢：重拍明确、推进感、结尾坚定。
- 想念：连贯、克制、句尾留有呼吸。

心情决定旋律轮廓、调式倾向和表达方式，不直接决定唯一 BPM。

### 4.2 律动模板

| 律动 | 当前 BPM | 人声适配倾向 |
| --- | ---: | --- |
| 稳稳走 | 88 | 整拍清楚、句尾留白，适合初次跟唱 |
| 蹦蹦跳 | 96 | 八分音符增加、弱起自然、停顿较短 |
| 摇一摇 | 84 | 使用摇摆拍位，但保持字词清晰 |
| 向前冲 | 108 | 重拍明确、第三句发展、结尾坚定 |

同一首诗覆盖多个律动的规则：

1. 先保留一条经过确认的音符级旋律母版。
2. Codex为每个目标律动调整起拍、音符时值、重音、句尾停顿和换气。
3. 每个适配版分别调用 DiffSinger 重新生成人声。
4. 不把母版 WAV 直接加速或减速作为正式版本。
5. 每个版本单独试听和审核；一个版本不通过，不影响其他版本发布。

儿童端只选择完全匹配“心情＋律动＋结构”的已审核歌曲包，不自动硬套不匹配的人声。

## 5. 二期生产流程

二期在教师或内容后台提前生成，不在儿童使用时临时生成：

1. **诗库筛选**：按心情、主题、字数、句数和年龄推荐 2—3 首候选诗。
2. **文本分析**：确认读音、多音字、分句、语义停顿、韵脚和关键词。
3. **节奏模板**：分配每个字的起拍、时值、句尾延长和换气。
4. **旋律候选**：在音域、音程、重复、调式和声调软约束下生成 2—4 条候选。
5. **规则初筛**：检查音域、大跳、机械等时值、句法、调性和长度。
6. **钢琴草稿**：先输出钢琴旋律加伴奏，由老师逐句确认。
7. **母版确认**：保存音符级旋律、歌词、节奏和结构，不能只保存 WAV。
8. **律动适配**：Codex从母版产生多个目标律动版本。
9. **人声合成**：Codex准备输入并调用 DiffSinger，生成整首和逐句人声。
10. **混音与检查**：合成完整作品，并自动检查进入小节、长度、调性、峰值和静音。
11. **人工审核**：检查儿童可唱性、歌词清晰度、诗意、句序、呼吸和响度。
12. **发布歌曲包**：只有通过审核的版本进入儿童端。

## 6. Codex 与 DiffSinger 的分工

### Codex负责

- 读取旋律母版和目标律动参数；
- 调整音符级节奏并生成统一歌曲 JSON；
- 生成 DiffSinger 推理输入并发起合成任务；
- 收集整首人声、拆分或整理四句练习音频；
- 与各律动伴奏混音；
- 生成自动检查报告和待审核歌曲包。

### DiffSinger负责

- 按已经确定的音符、歌词、时值和音色合成中文歌声；
- 输出可用于后续混音的人声文件。

DiffSinger不负责：选择古诗、作曲、判断儿童可唱性、决定句法或自动发布。

### 教师或内容人员负责

- 确认古诗、读音、旋律母版和律动适配结果；
- 试听歌词清晰度和儿童跟唱难度；
- 批准或拒绝每个歌曲包。

## 7. 工作流输入与输出

### 最小输入

- 古诗 ID、正文、作者、读音和心情标签；
- 音符级旋律母版，优先使用统一歌曲 JSON；
- 目标律动、BPM、拍号、调性和伴奏；
- 目标年龄和可唱音域；
- 合法可用的中文小兔音色。

可接受的母版格式按优先级排列：

1. 统一歌曲 JSON；
2. DiffSinger 工程或推理输入文件；
3. MIDI＋逐字歌词对齐；
4. 只有 WAV 时仅制作快速预览，不作为正式多律动母版。

### 标准输出

```text
poem-package/
├─ song.json                 # 唯一时间轴
├─ piano-preview.wav         # 钢琴草稿
├─ accompaniment.wav         # 伴奏
├─ vocal-full.wav            # 整首人声
├─ mix-full.wav              # 完整混音
├─ lines/
│  ├─ line-1.wav
│  ├─ line-2.wav
│  ├─ line-3.wav
│  └─ line-4.wav
└─ qa-report.json            # 自动检查结果和人工审核状态
```

统一歌曲 JSON 至少保存：诗、心情、律动、BPM、拍号、调性、前奏/演唱/尾奏小节数、音色、逐字音符、换气和版本状态。

## 8. 发布前验收

### 音乐与儿童可唱性

- 音域不超过目标范围，且可整体移调。
- 没有无理由的连续大跳、机械等时值或过长单字。
- 1—2 遍后能模仿核心旋律轮廓。
- 前奏能建立速度，尾奏有明确结束感。

### 文字与演唱

- 句序、读音、多音字、分句和韵脚正确。
- 每句有清楚换气，歌词在伴奏中可辨识。
- 关键词字调与旋律没有严重反向。
- 逐句音频和当前句一一对应。

### 技术与混音

- 人声只在指定演唱小节出现。
- 人声、伴奏、歌词、简谱和手势使用同一 BPM 和时间轴。
- 文件长度、采样率、声道、峰值和静音符合发布规范。
- 人声不遮蔽伴奏，伴奏也不遮蔽歌词。
- 儿童原有四段编排和动物出场保持不变。

## 9. 当前验证样例

当前样例为“想念＋稳稳走＋《静夜思》”：C 调、4/4、88 BPM，使用“2 小节前奏＋4 句演唱＋2 小节尾奏”。当前音频用于验证产品流程，不代表正式商业音色已经确定。

## 10. 待二期确认

- 首版是否只允许从平台审核诗库选择，还是开放老师自定义古诗。
- 教师可修改到逐句还是逐字音符级。
- 正式“小兔歌手”中文音色及商业授权。
- 首批歌曲包数量、人工审核人力和失败版本的补做策略。

若按 4 种心情、每种 2—3 首诗、每诗 4 种律动计算，首批需要 32—48 个适配歌曲包。

## 11. 研究依据

- [Elementary School Children’s Vocal Range](https://journals.sagepub.com/doi/10.2307/3344709)：儿童音域随年龄发展，但产品旋律不应使用最大能力作为默认范围。
- [Born to Speak and Sing](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.00948/full)：儿童歌唱从歌词与节奏中心逐步形成有限音域的旋律轮廓。
- [LingGe](https://www.ijcai.org/proceedings/2023/0842.pdf)：古诗歌曲生成先处理句式和节奏；古诗不强制使用五声调式。
- [Wee 2007](https://scholars.hkbu.edu.hk/en/publications/unraveling-the-relation-between-mandarin-tones-and-musical-melody-11/)：普通话字调与音乐旋律存在关系，但不应机械逐字对应。
- [Intoner](https://www.ijcai.org/proceedings/2025/1139.pdf)：吟诵需要同时处理字、句和全诗层级，韵脚应适度强调。
- `materials/义务教育艺术课程标准（2022年版）.pdf`：课程强调感知、表现、创造和中华优秀传统文化结合，并未规定古诗必须使用某一种调式。
