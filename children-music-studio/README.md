# 儿童音乐设计台

这是贴纸音乐素材的制作工作台。它在教师备课平台中作为“贴纸旋律创作”入口出现，用来支持儿童端“创作”模块；页面和运行入口已经合并到备课平台，代码与数据目录仍独立保存，不修改现有16套成品及主原型资源。

教师备课平台的另一项工作是“歌曲分析”，用于支持儿童端“感受”。两者职责分开：本工作台负责制作贴纸音乐素材，歌曲分析负责把上传音频匹配成旋律手势和身体动作。

## 使用方式

运行项目根目录的 `启动唱名教学原型.cmd` 后，从教师备课平台进入“贴纸旋律创作”即可直接使用，不需要再单独启动儿童音乐设计台。它的生成数据和正式音乐资源仍保存在本目录中。

新版流程：自由描述心情与律动 → 千问生成音乐设计卡 → 人工确认 → 生成并审核音乐 JSON → 试听 → 四分轨 → 保存到本项目自己的 `published-music`。

固定安全线：6—12 岁、C 大调、4/4 拍、两小节 8 拍、旋律/贝斯/萨克斯音域、和声合法性、时间网格、声部避让与萨克斯完整乐句检查。

## 线上演示模式

GitHub Pages 或 URL 带 `?demo` 时，工作台自动进入纯前端演示模式：

- 使用预先由千问生成并通过检查的“雨后晴天蹦蹦跳”固定数据；
- 心情输入为“夏天，下完雨后天晴了我很高兴”；
- 身体律动输入为“蹦蹦跳跳回家”；
- 设计卡、生产提示词、音乐 JSON、试听混音和四条分轨都从仓库中的固定音乐包读取；
- 页面不会调用千问、不会写入服务器，也不需要 API 密钥；
- 编辑、试听、分轨和发布按钮用于完整展示产品流程。

演示音乐包位于：

```text
prototype/assets/music/child_20260811_135323_a2048e_bounce/v01/
```

本地连接正式服务时才执行真实的千问生成、检查、渲染和发布流程。正式密钥只允许由服务端环境变量读取。
